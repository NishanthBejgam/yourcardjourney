Download & set up your tools

Everything you are licensed for sits in one folder. Read the five steps, download the setup file, then send me your machine ID for a licence code.

Setting up

Five steps, once per PC
1

Turn off Smart App Control

Windows Security App & browser control Smart App Control settings Off

Do this before you install. Recent Windows 11 builds block any app that does not carry a paid Microsoft certificate. These are custom-built tools made for you, so they have none. Nothing is wrong with them. You only need to do this once on the PC, not once per tool.

Expect a warning. Windows Defender or SmartScreen will flag an unrecognised app or unknown publisher during install — same reason. Choose More info → Run anyway. This appears on every new version, not just the first install.
2

Install your tools

The folder holds one setup file per tool you are licensed for, for example:

CardVaultSetup-1.0.4.exe

Download the setup file, run the ones you need and click through each installer. Always take the newest version listed in What’s new.

3

Send me your machine ID

Double-click any of the tools. A command window opens — that is the app’s own server. Leave it open. The tool itself opens in your browser.

The first screen shows YOUR MACHINE ID. Click Copy and send that code to me so I can issue your licence.

4

Activate

I will send back a licence code. Paste it in and click Activate — the tool unlocks straight away.

One code covers every tool on your licence. Activate once and use the same code in the other tools. You do not need a separate licence per tool.

The licence is generated for that PC only. If you move to another laptop the same setup files will not activate — message me and I will issue a fresh licence. To check your licence later, or paste a renewal code, use the licence chip in the app header.

5

Create your master password

The tools that hold your data — Card Vault, Gift Card Vault, Card Ledger and so on — ask you to set a master password on first unlock. It encrypts everything on your PC, and then you are free to start adding your details.

There is no reset, no recovery and no backdoor — deliberately. If you forget it, the data cannot be recovered by me or by anyone. Remember your master password and keep it somewhere safe.

While you are using it

Keep the command window open. Closing it stops that tool and locks your data.
Your data never leaves your PC. Everything stays encrypted on your computer. No cloud, no account, nothing is sent anywhere.
